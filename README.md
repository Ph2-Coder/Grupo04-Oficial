# Titulo
DESENVOLVIMENTO DE UM SISTEMA WEB PARA GERENCIAR OBJETOS ACHADOS E PERDIDOS NA ETEC DE CAMPO LIMPO PAULISTA 

## Descrição 
Um sistema de achados e perdidos que auxilia na organização e controle dos achados e perdidos, ajudando na comunicação entre comunidade e responsáveis pelo sistema, centralização de informações e registro de ocorrências

## Passo-a-passo
Para colocar o programa funcionando no computador de forma simples, siga os passos abaixo divididos em duas partes: a tela que você vê (parte visual) e o sistema que guarda os dados (servidor).
Primeiro, abra o programa Visual Studio Code e selecione a pasta onde o projeto está guardado. Abra a ferramenta de comandos (terminal) e entre na pasta que cuida da parte visual (frontend) digitando no terminal “cd frontend”. Logo em seguida digite o comando para baixar os arquivos necessários escrevendo “npm install” e aperte enter. Depois digite “npm run dev” para ligar essa parte. Se tudo der certo, vai aparecer um link azul na tela que você pode copiar e colar no navegador de internet para abrir a página.
Depois, para ligar a outra parte do sistema, abra uma nova aba de comandos, entre na pasta do servidor (backend) usando o comando “cd backend” e digite novamente o comando de instalação “npm install”. Em seguida, ligue o servidor digitando “npm run dev”. Se a conexão acontecer sem erros, o programa vai avisar que o banco de dados foi conectado, que os dados estão organizados e que o sistema está funcionando e rodando no endereço web padrão.
